# Icons

Placera dina applikationsikoner här:

- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)

Du kan generera ikoner med Tauri CLI:

```bash
npm install -g @tauri-apps/cli
tauri icon path/to/your-icon.png
```

Detta kommer automatiskt generera alla nödvändiga ikonstorlekar.
